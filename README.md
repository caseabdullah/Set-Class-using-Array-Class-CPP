# 🔢 Set Class Using Array Class | C++

### 📌 About the Project

This project implements a **Set Class using a custom Array Class** in C++, applying Object-Oriented Programming (OOP) concepts and class composition.

The `Set` class uses an `Array` object internally to store and manage elements while maintaining the fundamental properties of a mathematical set, including unique elements.

The project focuses on implementing set operations and understanding how custom classes can interact to build structured and reusable programs.

### 🛠️ Technologies & Concepts

- **Language:** C++
- **OOP Concepts:**
  - Classes and Objects
  - Encapsulation
  - Composition (Has-A Relationship)
  - Constructors and Copy Constructor
  - Destructors
  - Dynamic Memory Management (depending on Array implementation)

### ⚙️ Implemented Features

**1. Set Management**
- Check whether a set is full or empty.
- Add elements to a set.
- Remove elements from a set.
- Search for an element.
- Find the position of an element.
- Display set elements.

**2. Set Operations**
- **Union:** Combines elements from two sets.
- **Intersection:** Finds common elements between two sets.
- **Difference:** Finds elements present in one set but not the other.
- **Subset:** Checks whether one set is a subset of another.
- **Cartesian Product:** Displays the Cartesian product of two sets.

**3. Object Management**
- Parameterized constructor.
- Copy constructor.
- Destructor.

### 🧠 Key Learning Outcomes

- Understanding class composition through an Array object inside the Set class.
- Implementing mathematical set operations using arrays.
- Managing set capacity and element count.
- Applying constructors, copy constructors, and destructors.
- Understanding relationships between user-defined classes.
- Strengthening problem-solving and OOP programming skills.
